# Danberz Quality Tech - Website V2

A modern, responsive landing page for Danberz Quality Tech, an industrial supply partner for Oil & Gas and EPC Projects.

## Project Structure

*   `index.html` - Main landing page.
*   `assets/` - Images, CSS, and JavaScript files.
*   `libs/` - Third-party libraries (GSAP, Alpine.js, Lenis, etc.).

## Tech Stack

*   **HTML5 & CSS3**
*   **Tailwind CSS** (via CDN for styling)
*   **Alpine.js** (for interactivity and state management)
*   **GSAP** (for animations)
*   **Lenis** (for smooth scrolling)

## How to Run

Simply open `index.html` in any modern web browser. No build step or server is required for development.

## Features

*   **Responsive Design**: Optimized for everything from mobile phones to large 2XL screens.
*   **Performance Optimized**: Fast loading with optimized assets and preloading.
*   **Interactive Components**: Accordions, scroll animations, and a contact form simulation.
